## djazairdev

Open-source software for Algeria, built in the open by Algerian developers and everyone who wants to help.

### Projects

| Project | What it is |
|---|---|
| [djazair.dev](https://github.com/djazairdev/djazair.dev) | Algeria's developer ecosystem, live at [djazair.dev](https://djazair.dev): the Developer Index, from GitHub's data each quarter, and the Hub of open-source projects with issues for newcomers |
| [wilayas](https://github.com/djazairdev/wilayas) | Algeria's 69 wilayas, 538 daïras and 1,541 communes as a free API in JSON and CSV, from the official texts: [wilayas.djazair.dev](https://wilayas.djazair.dev/docs/) |
| [founders.coffee](https://github.com/djazairdev/founders.coffee) | Free local meetups for founders in Algeria, in Arabic, French and English: [founders.coffee](https://founders.coffee) |
| [Minhajna](https://github.com/djazairdev/minhajna) | A free, open-source app for Algeria's teachers, from the yearly plan to every lesson. In planning: there's no app yet |
| [Detent](https://github.com/djazairdev/detent) | A Claude Code plugin that turns planning documents into reviewed, test-gated code, with a deterministic referee |

### Start contributing

- Pick an issue labelled **good first issue** or **help wanted** in any project. The [Hub](https://djazair.dev/en/hub/) gathers them from projects across Algeria.
- Comment `/take` on it: it's assigned to you, and you can start straight away. Comment `/drop` if you stop.
- Read the project's CONTRIBUTING file, and our [code of conduct](https://github.com/djazairdev/.github/blob/main/CODE_OF_CONDUCT.md).

### Talk to us

- [Ask a question](https://github.com/orgs/djazairdev/discussions/categories/q-a) in our discussions, in Arabic, Tamazight, French or English.
- Follow djazairdev on [Facebook](https://www.facebook.com/djazairdev) and [X](https://x.com/djazairdev) for news.

### Bring your project

Make it djazairdev ready with the [project template](https://github.com/djazairdev/project-template): the files every project needs, and a prompt that sets them up with a coding agent. Then [list it in the Hub](https://github.com/djazairdev/djazair.dev/blob/main/CONTRIBUTING.md#list-a-project-in-the-hub).
