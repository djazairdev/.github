# Getting help

- **A question:** check the project's README first, then ask in [Q&A](https://github.com/orgs/djazairdev/discussions/categories/q-a), our discussions. Say what you tried and what happened.
- **A bug:** open an issue with the **Bug** form.
- **An idea for a project:** see [djazair.dev's guide](https://github.com/djazairdev/djazair.dev/blob/main/CONTRIBUTING.md#propose-a-project-idea).
- **A security problem:** don't open an issue; follow [SECURITY.md](https://github.com/djazairdev/.github/blob/main/SECURITY.md).
- **Someone's behaviour:** email conduct@djazair.dev ([code of conduct](https://github.com/djazairdev/.github/blob/main/CODE_OF_CONDUCT.md)).

Maintainers are volunteers. Projects listed in the djazair.dev Hub pledge to reply to newcomers' pull requests within 7 days.
