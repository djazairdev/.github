# Security

Please don't report a security problem in a public issue.

## Reporting a vulnerability

- **On GitHub:** open the repository's **Security** tab and choose **Report a vulnerability**. Only the maintainers see the report.
- **By email**, if you can't use GitHub: **security@djazair.dev**. Name the repository, and say how to reproduce the problem.

We reply within 7 days, keep you told of progress, and credit you in the fix unless you'd rather not be named. Please give us a reasonable time to fix the problem before you talk about it publicly.

## Which versions

We fix the latest release and the default branch. A repository can say more in its own `SECURITY.md`.
